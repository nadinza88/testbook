# Книжная мастерская NeuroGym — Cloudflare Workers

Эта версия переведена с Express/SQLite на Cloudflare Worker. В ней нет `express`, `better-sqlite3`, `fs` и других Node-only зависимостей, из-за которых прежняя сборка падала.

## Что сохранено
- интерфейс мастерской и читателя;
- API для создания сюжета и генерации иллюстраций;
- демо-режим без API-ключей;
- локальная библиотека в браузере (localStorage), даже если KV ещё не подключён;
- поддержка Cloudflare KV для хранения книг на стороне сервера;
- печать/сохранение книги в PDF через браузер.

## Как обновить GitHub
1. Распакуйте ZIP.
2. В репозитории GitHub загрузите содержимое папки проекта в корень репозитория, сохраняя папки `public`.
3. Commit changes. Cloudflare Workers Builds должен запустить новую сборку.
4. В логах сборки проверьте, что Worker теперь собирает `worker.js`, а не `server/index.js`.

## Настройка секретов для генерации ИИ
В Cloudflare Dashboard откройте Worker `testbook` → Settings → Variables and Secrets. Добавьте секреты:
- `OPENAI_API_KEY` — ключ OpenAI для генерации текста и, если отдельный ключ не задан, изображений;
- `IMAGE_API_KEY` — необязательный отдельный ключ для генерации изображений.

Если ключи не заданы, приложение работает в демо-режиме. Не записывайте секреты в GitHub и не добавляйте их в `wrangler.toml`.

## Настройка хранения книг между устройствами
Без KV книги хранятся в localStorage текущего браузера и не синхронизируются между устройствами.

Чтобы хранить их на стороне Cloudflare:
1. В Cloudflare Dashboard откройте **Storage & databases → KV** и создайте namespace, например `neurogym-books`.
2. Откройте Worker `testbook` → **Settings → Bindings → Add binding → KV namespace**.
3. Имя переменной (Variable name) укажите точно `BOOK_KV`; выберите созданный namespace и сохраните.
4. Повторно разверните Worker, если Dashboard предложит это сделать.

В `wrangler.toml` намеренно нет фиктивного ID KV: такой ID мешал бы корректному развёртыванию.

## Проверка
После деплоя откройте адрес Worker и убедитесь, что интерфейс загружается. Затем откройте `/api/status`: ожидается JSON с `"status":"ok"`. Создайте тестовую книгу и проверьте иллюстрацию и PDF.

## Локальная разработка
Требуется Node.js 20+:
```bash
npm install
npm run dev
```
Для локальных секретов создайте `.dev.vars` (не коммитьте этот файл) и добавьте, например:
```dotenv
OPENAI_API_KEY=ваш_ключ
IMAGE_API_KEY=ваш_ключ_для_изображений
DEMO_MODE=false
```
